# AAPL Stock Exploratory Analysis

Exploring & Analyzing Data final project (M.Sc. Data Science). Statistical exploration of AAPL daily stock data across 2023-2024: cleaning, resampling to multiple frequencies, trend/level metrics, and a year-over-year comparison.

## Pipeline

1. `dataset_preprocessing.py` — cleans the raw daily AAPL price data and derives multiple sampling frequencies (daily, first-day-of-month, Jan-only, Feb-Dec split) for 2023 and 2024.
2. `main.py` — runs the core statistical analysis: level and trend metrics per period, produces comparison tables between 2023 and 2024, and an adjustment/robustness check.

## Outputs (generated by the scripts)

- `results/Part_B_2023/` and `results/Part_C_2024/` — level & trend metrics and plots for each year
- `results/Part_D_Comparison/` — year-over-year comparison table
- `results/Part_E_Adjustment/` — adjusted metrics and plot
